# WTZY 国际转运系统（UI2）

自己写的国际转运系统 —— 界面使用**光年模板**（光年 v5 设计体系）：统一的现代设计语言，服务端直出渲染，不依赖 Vue、React 等前端框架，无前端构建流程。

> 本仓库为系统**稳定版（stable）**代码快照，当前版本：**v0.6.1**（全站界面光年模板升级版；含站点品牌素材上传与三端登录验证码）。

## 系统概览

覆盖国际转运（集运）业务完整流程：海外仓收货 → 包裹入库 → 集包打包 → 运输出库 → 清关派送，配套会员、财务与售后体系。

| 端 | 主要功能 |
|---|---|
| 官网 · 会员中心 | 注册登录、包裹预报与集运、运单与物流跟踪、余额充值（在线支付）、发票申请、会员等级与积分、优惠券与邀请、工单与理赔、消息通知 |
| 管理后台 | 控制台、用户与实名审核、包裹 / 订单 / 运单管理、渠道费率与报关配置、客服工单、财务流水与报表、发票管理、营销与会员体系、仓库与员工权限 |
| 仓库工作台 | 入库登记、打包集包、仓储管理、出库交接、异常件处理、任务列表 |
| 开放 API | 按令牌授权的对外数据接口 |

## 界面说明（光年模板）

- 全站界面使用**光年模板**（光年 v5）统一构建：三端后台、会员中心与系统页共享同一套布局、组件与交互规范；
- 页面由 PHP 服务端直出渲染，浏览器即开即用；
- 样式由光年模板基础资源与统一主题层构成，支持桌面（1280px+）与移动端；
- 交互使用原生 JavaScript 封装（确认弹窗、全局通知、局部刷新、轮询等），无第三方 UI 框架依赖。

## 技术栈

- 服务端：PHP 8.5+（`strict_types` 严格模式）、MySQL 5.7+（InnoDB / utf8mb4）
- 前端：光年模板（HTML / CSS / JavaScript，无框架、无构建步骤）
- 部署：内置**一键安装向导**（六步：环境检测 → 数据库 → 管理员 → 系统配置 → 执行安装 → 完成），自带升级脚本

## 目录结构

```
├── app/            应用代码（控制器 / 模型 / 视图 / 枚举）
├── config/         配置（应用 / 数据库 / 界面）
├── install/        一键安装向导（页面 + 建表脚本 + 升级脚本）
├── public/         站点入口（Web 根目录，含静态资源）
├── routes/         路由定义
├── tasks/          计划任务（定时脚本）
├── storage/        运行期存储（日志等）
├── deploy/         部署参考配置
├── common.php      公共引导文件
└── .env.example    环境配置模板
```

## 安装部署

1. 运行环境：PHP 8.5+ / MySQL 5.7+，Web 根目录指向 `public/`；
2. 首次访问站点根地址，会自动进入**安装向导**，按六步提示完成安装；
3. 安装完成后，后台可修改站点名称、支付、仓库等全部配置。

> 数据库账号密码等运行环境配置（`.env`）由安装向导自动生成，仓库中不包含任何真实密钥与配置文件。
